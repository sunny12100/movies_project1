# Netflix GPT

Netflix GPT is an AI-powered platform that helps users discover personalized movie and TV show recommendations. By leveraging the power of Gemini AI and integrating with the TMDB API and Anime API, Netflix GPT provides curated suggestions based on user preferences, mood, and trending content.

---
## 🚀 Tech Stack

- **Frontend**: React, Redux , Tailwind CSS
- **Backend**: Firebase
- **APIs**: TMDB API, Gemini AI , ANIME API

---

## 🛠️ Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/netflix-gpt.git
   ```

2. Navigate to the project directory:
   ```bash
   cd netflix-gpt
   ```

3. Install dependencies:
   ```bash
   npm install
   cd client && npm install
   ```

4. Set up environment variables in a `.env` file:
   ```env
   GEMINI_API_KEY=your_api_key
   TMDB_API_KEY=your_tmdb_api_key
   ```

5. Start the development servers:
   ```bash
   # Start the backend server
   npm run dev
   
   # Start the frontend server
   cd client && npm start
   ```

6. Visit the app at `http://localhost:3000`.
